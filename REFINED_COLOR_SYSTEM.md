## 🎨 **Refined Color System**

### **1. BASE UI COLORS (Neutral - Main UI)**
Used for: Backgrounds, cards, surfaces, layout

```
neutral-50:  #fafafa  - Ultra-light backgrounds
neutral-100: #f5f5f5  - Card backgrounds
neutral-200: #e5e5e5  - Borders, dividers
neutral-300: #d4d4d4  - Subtle borders
```

**Usage**: 90% of the UI uses these clean neutrals

### **2. TEXT COLORS (Neutral - Typography)**
Used for: All text content

```
neutral-900: #171717  - Dark headings
neutral-800: #262626  - Headings
neutral-700: #404040  - Primary text
neutral-600: #525252  - Body text
neutral-500: #737373  - Secondary text
neutral-400: #a3a3a3  - Disabled states
```

**Usage**: Professional, high-contrast typography

### **3. ACCENT COLORS (Lavender - Highlights ONLY)**
Used for: CTAs, active states, focus rings, selected items

```
lavender-600: #8b6fb0  - Primary CTA buttons
lavender-500: #9b7ebd  - Focus rings, active states
lavender-100: #f4f1ff  - Hover backgrounds
lavender-50:  #faf8ff  - Subtle hover states
```

**Usage**: 10% of the UI - intentional highlights only

### **4. SECONDARY ACCENTS (Purple/Periwinkle)**
Used for: Charts, badges, success states

```
purple-500:     #a855f7  - Chart accents
periwinkle-500: #8b93ff  - Info states
green-500:      #22c55e  - Success states
```

**Usage**: Rare, for data visualization and special states
